## 📋 Описание проекта

Проект представляет собой Python-приложение для автоматического получения показаний электросчётчика **Энергомера CE308** через устройство считывания **CE901 BU-04**. Паять и собирать схемы не требуется. Все что нужно - наличие CE901 BU04 и microUSB кабеля!

Приложение выполняет следующие задачи:

- 🔌 Подключается к CE901 через USB и последовательный порт.
- 📡 Обменивается данными со счётчиком по протоколу DLMS/COSEM через радиоканал.
- ⚡ Считывает показания активной энергии по регистрам `1.8.0`, `1.8.1` и `1.8.2`.
- ⚡ Считывает значения напряжения по фазам 1 2 3 в В.
- 📤 Публикует показания и состояние опроса в MQTT.
- 🏠 Автоматически создаёт сущности Home Assistant через MQTT Discovery.
- 🎛️ Позволяет изменять интервал опроса и запускать внеочередной опрос через MQTT.
- 📊 Предоставляет данные для графиков, статистики и автоматизаций умного дома.

### Для чего это нужно?

- Контроль общего потребления электроэнергии.
- Анализ расхода электроэнергии по тарифам.
- Построение графиков потребления в Home Assistant.
- Автоматизация устройств в зависимости от энергопотребления.
- Уведомления о превышении заданных порогов потребления и тд.

## 🔧 Схема работы

```text
┌──────────────────────┐
│  Энергомера CE308    │
│  Электросчётчик      │
└──────────┬───────────┘
           │
           │ Радиоканал 433 МГц
           │ DLMS/COSEM
           ▼
┌──────────────────────┐
│   CE901 BU-04        │
│   Радиосчитыватель   │
└──────────┬───────────┘
           │
           │ USB / Serial
           │ 115200 8N1
           ▼
┌──────────────────────┐
│   Python-приложение  │
│   Опрос и обработка  │
└──────────┬───────────┘
           │
           │ MQTT
           ▼
┌──────────────────────┐
│    MQTT-брокер       │
│ Mosquitto / EMQX     │
└──────────┬───────────┘
           │
           │ MQTT Discovery
           ▼
┌──────────────────────┐
│    Home Assistant    │
│ Сенсоры и управление │
└──────────────────────┘
```

### Используемые протоколы

| Соединение | Протокол / интерфейс | Параметры |
|---|---|---|
| CE901 ↔ CE308 | DLMS/COSEM | Радиоканал 433 МГц |
| Хост ↔ CE901 | USB / последовательный порт | 115200, 8N1 |
| Приложение ↔ MQTT | MQTT | TCP/IP |
| MQTT ↔ Home Assistant | MQTT Discovery | TCP/IP |

> Примечание: фактические параметры радиоканала, режим обмена и поддерживаемые версии протокола зависят от прибора учета и его прошивки.


Укажите параметры подключения к CE901, пароль счётчика (**установленный по умолчанию производителем: 12345678**) и адрес MQTT-брокера.

**Вариант A — локальный запуск:**

```bash
docker compose up -d --build
```

Убедитесь, что USB-устройство обнаружено:

Если приложение запущено непосредственно в системе, проверяйте вывод процесса или настроенный файл журнала.

## ⚙️ Конфигурация

Настройки приложения задаются через файл `.env`.

### Аппаратные параметры

| Переменная | Описание | Значение по умолчанию | Обязательная |
|---|---|---|:---:|
| `COM_PORT` | Последовательный порт CE901 | `/dev/ttyUSB0` | Да |
| `BAUDRATE` | Скорость последовательного порта | `115200` | Нет |
| `TIMEOUT` | Таймаут ожидания ответа, секунд | `3` | Нет |
| `PASSWORD` | Пароль доступа к счётчику | `12345678` | Да |
| `POLL_INTERVAL` | Интервал опроса, секунд | `300` | Да |

Допустимый диапазон `POLL_INTERVAL`: от `10` до `3600` секунд.

### MQTT-параметры

| Переменная | Описание | Значение по умолчанию | Обязательная |
|---|---|---|:---:|
| `MQTT_BROKER` | Адрес MQTT-брокера | `localhost` | Да |
| `MQTT_PORT` | Порт MQTT-брокера | `1883` | Нет |
| `MQTT_USER` | Имя пользователя MQTT | Пусто | Нет |
| `MQTT_PASS` | Пароль MQTT | Пусто | Нет |
| `MQTT_TOPIC` | Базовый MQTT-топик | `energomera/ce308` | Нет |
| `MQTT_CLIENT_ID` | Идентификатор MQTT-клиента | `ce308_poller` | Нет |

### Параметры Home Assistant

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `HA_DEVICE_ID` | Уникальный идентификатор устройства | `ce308_energy_meter` |
| `HA_DEVICE_NAME` | Отображаемое имя устройства | `Счётчик CE308` |

### Пример файла `.env`

```dotenv
# Настройки CE901 / CE308
COM_PORT=/dev/ttyUSB0
BAUDRATE=115200
TIMEOUT=3
PASSWORD=12345678
POLL_INTERVAL=300

# MQTT
MQTT_BROKER=192.168.1.10
MQTT_PORT=1883
MQTT_USER=
MQTT_PASS=
MQTT_TOPIC=energomera/ce308
MQTT_CLIENT_ID=ce308_poller

# Home Assistant
HA_DEVICE_ID=ce308_energy_meter
HA_DEVICE_NAME=Счётчик CE308

#Используется для разных окружений dev/main
PROJECT_PREFIX=main #dev/main
```

Замените `192.168.1.10` на IP-адрес вашего MQTT-брокера. Если брокер требует авторизацию, укажите имя пользователя и пароль.

## 📡 MQTT-интеграция

Базовый топик по умолчанию:

```text
energomera/ce308
```

### Командные топики

| Топик | Назначение | Пример значения |
|---|---|---|
| `energomera/ce308/set/poll_interval` | Изменить интервал опроса | `60` |
| `energomera/ce308/set/poll_now` | Запустить внеочередной опрос | `1` |


### Примеры сообщений

Пример сообщения с показаниями:

```json
{
  "value": 12345.678,
  "unit": "kWh"
}
```

### Управление через `mosquitto_pub`

Изменить интервал опроса на 60 секунд:

```bash
mosquitto_pub \
  -h 192.168.1.10 \
  -t 'energomera/ce308/set/poll_interval' \
  -m '60'
```

Запустить опрос немедленно:

```bash
mosquitto_pub \
  -h 192.168.1.10 \
  -t 'energomera/ce308/set/poll_now' \
  -m '1'
```

Подписаться на все топики счётчика:

```bash
mosquitto_sub \
  -h 192.168.1.10 \
  -t 'energomera/ce308/#' \
  -v
```

При использовании авторизации добавьте параметры:

```bash
-u 'MQTT_USER' -P 'MQTT_PASSWORD'
```

## 🏠 Home Assistant

### Автоматическое обнаружение сущностей

При включённом MQTT Discovery и корректной публикации конфигураций Home Assistant сможет автоматически создать сущности счётчика.

### Сенсоры

| Entity ID | Название | Единицы | Описание |
|---|---|---|---|
| `sensor.ce308_energy_meter_1_8_0` | Активная энергия — всего | кВт·ч | Суммарное потребление |
| `sensor.ce308_energy_meter_1_8_1` | Активная энергия — тариф 1 | кВт·ч | Потребление по тарифу 1 |
| `sensor.ce308_energy_meter_1_8_2` | Активная энергия — тариф 2 | кВт·ч | Потребление по тарифу 2 |
| `sensor.ce308_energy_meter_status` | Статус опроса | — | `ok` / `error` |
| `sensor.ce308_energy_meter_last_update` | Последнее обновление | — | Время последнего опроса |
| `sensor.ce308_energy_meter_poll_interval` | Интервал опроса | с | Текущий период опроса |

### Элементы управления

| Entity ID | Название | Тип | Описание |
|---|---|---|---|
| `number.ce308_energy_meter_poll_interval_set` | Интервал опроса | Number | Изменение интервала от 10 до 3600 секунд |
| `button.ce308_energy_meter_poll_now` | Опросить сейчас | Button | Запуск внеочередного опроса |

Фактические `entity_id` могут отличаться в зависимости от discovery-конфигурации и уже существующих сущностей Home Assistant.

### Настройка MQTT

1. Откройте **Настройки → Устройства и службы**.
2. Добавьте интеграцию **MQTT**, если она ещё не настроена.
3. Укажите адрес брокера, порт и учётные данные.
4. Убедитесь, что Home Assistant подключён к нужному брокеру.
5. Запустите приложение и дождитесь публикации discovery-сообщений.
6. Проверьте появление устройства и его сущностей.

## 🔍 Устранение неполадок

### Скрипт не видит CE901

Проверьте наличие последовательного порта:

```bash
ls -l /dev/ttyUSB*
dmesg | tail -n 50
```

Дополнительно проверьте:

- правильность `COM_PORT` в `.env`;
- исправность USB-кабеля и разъёма;
- права доступа к устройству;
- отсутствие другого процесса, использующего порт;
- корректность скорости `BAUDRATE`;
- проброс USB-устройства в Docker.

### Ошибка авторизации

- Проверьте значение `PASSWORD` в `.env`.
- Убедитесь, что используется правильный пароль счётчика.
- Проверьте качество радиосвязи между CE901 и CE308.
- Проверьте режим работы счётчика и считывателя согласно их руководствам.
- При необходимости изучите журнал обмена и параметры протокола.

### Нет ответа от счётчика

- Увеличьте `TIMEOUT`, например до 5–10 секунд.
- Проверьте расстояние между считывателем и счётчиком.
- Убедитесь, что CE901 работает в штатном режиме.
- Проверьте питание считывателя.
- Повторите попытку после проверки радиосвязи.

### Сенсоры не появляются в Home Assistant

- Проверьте подключение MQTT в логах приложения.
- Убедитесь, что Home Assistant использует нужный MQTT-брокер.
- Проверьте адрес и порт в `MQTT_BROKER` и `MQTT_PORT`.
- Проверьте discovery-топики с помощью MQTT Explorer.
- Убедитесь, что приложение действительно публикует конфигурации сущностей.
- Перезапустите приложение и проверьте логи.

### Ошибка `ReadTimeoutError` при сборке Docker

Проверьте интернет-соединение, DNS и доступность реестра Docker.

Повторите сборку:

```bash
docker compose build --no-cache
docker compose up -d
```

Если проблема сохраняется, проверьте настройки прокси и доступность используемых базовых образов.
